# Purpose

Let the next agent (or engineer) skip re-learning what the team already knows about our NPU framework gits.

Questions this knowledge base must answer quickly:
1. I see error string X — have we seen it, and what caused it?
2. Op Y is unsupported / slow on HTP arch Z — what did we do last time?
3. Where in our gits does feature W live, and how do I build and test it?
4. What are the known traps (version skew, DSP library paths, quantization encodings) for this area?
